# ❌⭕ Tic Tac Toe

A simple browser-based Tic Tac Toe game built with **HTML, CSS and JavaScript**.

### 🎮 Live Demo

🔗 **[Play Tic Tac Toe](https://rupesshhh-coder.github.io/tic-tac-toe/)**

### ✨ Features

* ❌⭕ Two-player gameplay
* 🏆 Winner detection
* 🤝 Draw detection
* 🔄 New Game & Reset

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

### ▶️ Run Locally

Open `index.html` in any modern web browser.
